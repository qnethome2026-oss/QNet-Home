=== clean Ctrl-C =======================================================
Git Bash's `kill -INT` does not deliver a console CTRL_C_EVENT on Windows - it
terminates the process outright, so it proves nothing about the handler. The
handler is what a real Ctrl-C runs (console handler -> interrupt_main ->
KeyboardInterrupt in the main thread), so it is driven directly:

$ cat verify/ctrlc.tmp.py
import _thread, threading
from qnet.agent.__main__ import main
threading.Timer(3.0, _thread.interrupt_main).start()   # == pressing Ctrl-C at t+3s
rc = main(["--config", "config/house.yaml", "--no-llm"])
print(f"exit code: {rc}")
