── Incidents found & fixed during verification (all in this task's diff) ──────
* room-echo bug: the first live reply carried "room": null — answer_look was
  echoing the broadcast's TARGET room filter instead of the node's own room.
  Fixed; regression-pinned in test_answer_look_room_is_ours_not_the_broadcasts.
* silent MQTT wedge: after a Wi-Fi drop the paho loop_forever client sat alive
  with no socket and never reconnected (confirmed via /proc: 1 banner, no TCP,
  main thread idling) — the node missed a live agent broadcast. Restructured:
  paho network thread never blocks (on_message only enqueues), a worker thread
  does frame+VLM+publish (also removes keepalive starvation risk from ~30 s VLM
  stalls), and the main thread watchdogs is_connected() every 5 s and forces
  reconnect. Stale queued looks (>15 s) are dropped, not answered late.
* prompt parroting: giving the 4B an example location phrase made it echo the
  example verbatim into a found=false guide reply. Examples removed from both
  prompts; parse_reply now forces answer="" whenever found=false (a location
  for something not seen is confabulated by definition).
* dev/spy.py fixed client id: two spies (one left over on the board from T4.2)
  kicked each other off the broker in an endless reconnect loop. Client id now
  unique per process.
