=== notes / deviations =================================================
* IMPLEMENTATION's T3.4 verify block suggests `pytest tests/test_scenarios.py
  --llm`. Not added, deliberately: those four scenarios run at dev.timer_scale
  0.05, which turns fall.md's 30 s check timer into 1.5 s - shorter than a
  model turn plus its retry. A `--llm` run of them would be a test of whether
  the device beats a 1.5 s timer, not of the model. The equivalent assertions
  run at real timings in tests/test_llm_replay.py (the escalation path and the
  pain double-check, both live), and the smoke above is the same walk on a real
  broker. The hermetic suite stays hermetic.
* Config: `llm: {base_url: ...}` added to config/house.yaml, optional, default
  http://127.0.0.1:18181/v1. On the IQ-9075 that is the local GenieX server;
  from a laptop, SSH-tunnel 18181 first.
* Processes: the demo broker was reused, never started or stopped by this task.
  The smoke agent was stopped afterwards. The SSH tunnel on 18181 was already
  running when this task started (someone else's `ssh -f -N -L 18181:...`), so
  the one started here failed to bind and was killed; the pre-existing forward
  was used and left up rather than pulled out from under another session. Kill
  it with `taskkill /PID <pid>` when the workshop is done with the endpoint.
